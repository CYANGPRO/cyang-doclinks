# Local 801 Engage Admin Guide

Private preview starts with synthetic roles:
- System Owner: complete administrative authority.
- Local Administrator: broad Local 801 administration.
- Membership Data Manager: imports, matching, roster review, and authorized reporting.
- CAT Administrator: campaigns, assignments, CAT actions, and strategy within scope.
- CAT Lead: team-scoped assignments and follow-ups.
- CAT Member: assigned outreach, authorized search, engagement entry, and follow-ups.
- Report Viewer: reporting access without mutation rights.

Use the sign-in screen to switch synthetic preview roles. Production must use invitation-only authentication with MFA.

Authenticated web reports in the application are the sole reporting system.
