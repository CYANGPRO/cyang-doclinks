# Data Classification

Local 801 Engage treats roster records, personal contact details, membership status, engagement notes, assignments, restricted CAT strategy, source files, generated reports, audit records, and push subscriptions as sensitive.

Do not place sensitive data in local storage, IndexedDB, service-worker caches, manifest files, query strings, notification text, telemetry, screenshots, tests, seed files, or docs.

Synthetic data must use fictional names and `example.test` addresses.
