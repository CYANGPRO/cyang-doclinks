# Power BI Integration

Power BI readiness is implemented through read-only reporting views, but the connection is disabled by default.

Future enablement requires an owner-controlled Microsoft account, a read-only database role limited to approved views, organization filtering, row-level security, small-cell protections, scheduled refresh ownership, credential rotation, and a disablement plan.

Do not use Publish to web, anonymous iframes, public embedding, state Microsoft accounts, state workspaces, or public database credentials.
