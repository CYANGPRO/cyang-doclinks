# Native Mobile Packaging

The PWA can later be wrapped with Capacitor or an equivalent tool after owner approval.

Future work requires Apple Developer and Google Play developer accounts, deep-link planning, passkey and biometric-backed WebAuthn review, Face ID and fingerprint policy decisions, push-notification entitlement setup, privacy disclosures, app-store security review, and confirmation that sensitive data is not stored in native device caches.

No App Store or Google Play build is part of the MVP.
